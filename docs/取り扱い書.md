# 入金管理台帳 取り扱い書

自社割賦（車の自社ローン）の入金を管理する台帳です。
**誰がいくら払ったか・誰が遅れているか・誰にいつ電話したか**を、この1か所に残します。

使う方は2種類です。

- **電話を受ける担当者** — おもに「未入金」タブと、お客様のページを使います
- **経営者** — おもに「ダッシュボード」で数字を見ます

はじめての方は、次の「覚えることは3つだけ」と「一日の流れ」を読めば動けます。
細かい操作は、必要になったときに該当のところだけ読んでください。

---

## 覚えることは3つだけ

### 1. 支払期日は動きません

「来週払います」と言われて約束を入れても、**契約上の支払期日は変わりません**。
約束は「いつ払うと言ったか」の控えです。期日そのものを書き換えるものではありません。

以前は約束のたびに期日を動かしていましたが、分割の約束を何件も入れると
期日が跳ね回り、契約上いつが期日だったのか分からなくなったため、やめました。

### 2. 記録は消えません

入金を取り消しても、「取り消した」という記録が残ります。
メモを消しても、「消した」という記録が残ります。

**だから、思い切って直して構いません。** 間違いを隠すことはできませんが、
間違いを直すことはいつでもできます。放置するほうが困ります。

### 3. 迷ったらテスト顧客で試す

「設定」タブの **「テスト用の顧客を用意する」** を押すと、練習用のお客様が1件できます。
入金・約束・メモ・CSVの取り込みを、いくらでも試せます。
顧客一覧では <kbd>テスト</kbd> の印が付き、経営者が見る数字にも入りません。

**本物のお客様で練習しないでください。** 分からなくなったら、作り直せます。

## 入り方と出方

### 入る

利用者名とパスワードを入れて「ログイン」を押します。
一度入れば**8時間**そのまま使えます。翌日はもう一度入れてください。

### 出る

右上の **「ログアウト」** を押します。
みんなで使うパソコンでは、席を離れる前に必ず押してください。

### 大事な注意

ログインは**全員で同じもの**を使っています。そのため、
**入力した人の名前は残りません**（記録者はすべて「管理者」と出ます）。

誰がやったかを残したいことは、**メモに書いてください。**
（例：「8/9 田中が電話。給料日後に半分入れると本人が言っている」）

## 画面の地図

上に8つのタブが並んでいます。

| タブ | 何をする画面か | よく使う人 |
|---|---|---|
| **ダッシュボード** | 月ごとの回収の状況。開いた直後はここ | 経営者 |
| **顧客一覧** | 全員の一覧。名前を探して開く | 両方 |
| **入金登録** | 銀行のCSVを取り込む／手で1件入れる | 担当者 |
| **入金履歴** | 入れた入金を見る・直す・取り消す | 両方 |
| **未入金** | 期日を過ぎて払えていない方の一覧。**電話はここから** | 担当者 |
| **完済/引き上げ** | 終わった取引。払い終えた方と、車を引き上げた方 | 両方 |
| **設定** | 債権会社の登録。テスト用の顧客を作る | 経営者 |
| **デバッグ依頼** | おかしいところを報告する | 両方 |

## 一日の流れ（担当者）

### ① 朝、ダッシュボードを見る

台帳を開くと、まずダッシュボードが出ます。
**月ごとに、何％回収できたか**が並びます。100%になった月は消えます。

上に赤い帯で「約束切れが◯件あります」と出ることがあります。
**払うと言った日を過ぎた方**です。その日のうちにかけてください。

### ② 「未入金」タブを開く

期日を過ぎて払えていない方が、あいうえお順で並びます。
上から順にかけていけば、かけ忘れが出ません。

名前の横の印を見れば、その方の状況が分かります。

| 印 | 意味 |
|---|---|
| <kbd>13日 遅れ</kbd> | 期日を過ぎた日数 |
| <kbd>未督促</kbd> | **まだ電話していません。ここからかけます** |
| <kbd>督促 8/5</kbd> | 8月5日に連絡済み |
| <kbd>約束 8/20</kbd> | 8月20日に払うと言っています |
| <kbd>約束 8/5 超過</kbd> | **払うと言った日を過ぎています。優先してかけます** |
| <kbd>月額</kbd> / <kbd>ボーナス</kbd> | どちらの支払いの話か（ボーナス払いの方だけ出ます） |

**ボーナス払いの方は、月額の行とボーナスの行が別々に並びます。**
同じ名前が縦に2行出ることがありますが、間違いではありません。
金額も期日も別のものなので、**どちらの話をしているか確かめてから**話してください。
月額3万円とボーナス10万円では、話がまるで違います。

### ③ 電話をかける

行を押すと、そのお客様のページが開きます。
左にカレンダー、右に支払いの記録が出ます。

かける前に見ておくとよいところ:

- **カレンダー上の帯** — 月々の金額、次の支払期日、いまの回、残債
- **支払いの記録** — 過去にいつ・いくら入ったか。遅れがちな方かどうか分かります
- **この顧客についてのメモ** — 連絡のつきやすい時間、勤務先、家族のことなど

### ④ 電話を切ったら、すぐ控える

**あとでまとめて、はやめてください。** 忘れます。

- **連絡した** → 未入金タブの <kbd>未督促</kbd> を押す
- **払う日を言われた** → カレンダーのその日を押して、入金約束を入れる
- **事情を聞いた** → 支払いの記録の、その回を押してメモを足す

### ⑤ 入金が来たら登録する

「入金登録」タブから入れます。次の章で説明します。

## 電話まわりの操作

### 督促したことを控える

**未入金タブ**で、名前の横の <kbd>未督促</kbd> を押します。
確認が出るので「OK」を押すと、<kbd>督促 8/9</kbd> に変わります。

- 何度もかけたときは <kbd>督促 8/9（3回）</kbd> のように回数が出ます
- 間違えて押したら、もう一度押せば取り消せます
- **督促は「回」ごとに控えます。** 次の月になれば、また「未督促」から始まります
- ボーナス払いの方は、月額とボーナスで**別々に**控えられます

**取り消したあとは、元に戻せます。**

取り消すと、印は <kbd>未督促（8/9を取消）</kbd> に変わります。
かっこの中は「いつの督促を取り消したか」です。
**この印をもう一度押すと、どうするかを聞き直します。**

| 選ぶもの | どうなるか |
|---|---|
| **取り消す前に戻す** | 押し間違えたとき。**日付も回数も、取り消す前のまま**に戻ります |
| **今日、あらためて連絡した** | 取り消したのは正しくて、今日また電話したとき。今日の日付で、1回目から数え直します |
| やめる | 何もしません |

取り消した中身は消えません。**顧客ページの「記録」にも、いつ・何回目ぶんを
取り消したか、元に戻したかが残ります。**

### 入金月を変える（払いの立て直し）

「今月は払えない。11月から仕切り直したい」と言われたときに使います。

**顧客ページ →「支払いの記録」の右上「入金月変更」**

- **未払いの回から先だけを、まとめてずらします**
- **払い終えた回は動きません。入金の行き先も動きません**
- 金額・回数・残債も変わりません
- ボーナスの回も、同じだけ一緒にずれます
- 日はいまのままです。その月に無い日は末日にします
- 押す前に「◯月◯日 → ◯月◯日（3か月あと）」と、ずれる回数を出します

**変更の理由は必ず書いてください。**書かないと変更できません。
書いた理由は**支払いの記録にそのまま出ます**ので、次に電話を受けた人が読めます。

> 支払日を 2026-03-27 → 2026-06-27 に変更（3か月あと）。入院のため、6月から再開すると本人と合意

顧客情報の「支払い開始月」との違い:

| | 何をずらすか | いつ使うか |
|---|---|---|
| 顧客情報の**支払い開始月** | **全部の回** | 登録のときに月を間違えた |
| 支払いの記録の**入金月変更** | **未払いの回から先だけ** | 払えなくなって、仕切り直す |

### 入金約束を入れる

お客様のページの**カレンダー**で、払うと言われた日を押します。
下に欄が出るので、次を入れて「登録する」を押します。

| 欄 | 入れるもの |
|---|---|
| どの回ぶん | 何月分の話か。分からなければ「決めない」で構いません |
| いくら入金 | 言われた金額 |
| いつまで | 終日のままでよいです。「17時まで」と言われたらチェックを外して時刻を入れます |
| メモ | 言われたことをそのまま（例：給料日後、家族が払う） |

**1つの回に何件でも入れられます。**
「3日後に半分、5日後に残り」も、そのまま2件入れてください。上書きされません。

過ぎた日には入れられません。これから払う約束のための欄だからです。

### 約束を直す・取り消す

同じ日をもう一度押すと、その日の約束が一覧で出ます。
**「編集」**で直せます。**「削除」**で取り消せます。取り消したことは記録に残ります。

### 支払いの記録にメモを足す

お客様のページの右側、**支払いの記録の「回」を押す**と、下に入力欄が出ます。
書いて「メモを足す」を押します。

- 書いた**日と時刻は自動で入ります**。入れ間違いが起きません
- 続けて何件でも足せます（欄は開いたままです）
- 送るのは「メモを足す」ボタンか、**Ctrl + Enter**（文章なので Enter は改行です）
- **ボーナスの回にも足せます。** 賞与1回目のメモと、通常1回目のメモは別々に残ります

入金約束を入れると、その回に自動でメモが1行足されます。
自動で入ったメモは、約束のほうを直せば一緒に変わります。

### お客様についてのメモ

お客様のページの左下にあります。
**その方についてずっと残しておきたいこと**を書きます。

例：連絡のつきやすい時間、勤務先、家族のこと、事情

回ごとのメモとは別ものです。回ごとのメモは「その月の話」、こちらは「その人の話」です。

## 入金を入れる

### 銀行のCSVから取り込む（まとめて）

1. 「入金登録」タブを開きます
2. **点線の枠にCSVファイルを放す**か、枠を押してファイルを選びます
   （スマホ・タブレットでは、枠を押して選んでください）
3. **取り込む前の確認が、画面いっぱいに開きます。** ここで必ず確かめてください
4. よければ「◯件を取り込む」を押します（やめるときは「キャンセル」）

ファイルは**1つずつ**入れてください。表計算のファイル（.xlsx）や画像は取り込めません。
銀行の画面から、CSV形式で落としたものを使ってください。

確かめるところ:

- **すでに取込済み** の印が付いた行は、最初から外れています。そのままで構いません
- **重複** の印は、同じファイルの中に同じ入金が2つあるという意味です
- **顧客の欄が選択式になっている行**は、名前が結びつきませんでした。選んでください。
  選択肢は**顧客一覧と同じあいうえお順**で並んでいます
- **「◯行は取り込みません」**と出たら、中身を開いて確かめてください。
  出金や訂正の行ならそのままで構いません。入金のはずの行が入っていたら、
  ファイルの列の並びが違う可能性があります

### 入金種類（月額かボーナスか）

確認の表には、顧客の右に**「入金種類」**の欄があります。

- **はじめは「月額 ¥30,000-」**が入っています。たいていはそのままで結構です
- **ボーナス払いの設定がある方だけ**、「ボーナス ¥100,000-」も選べます
- 金額はその方の月々の支払額・ボーナス額です。**顧客を選ぶと出ます**

賞与の振り込みだと分かっている行は、ここを**「ボーナス」**に変えてください。
ボーナスの回にだけ充てます。

**なぜ選ぶのか。** 台帳は期日の古い順にお金を充てます。振込人名からは、その入金が
月額ぶんなのかボーナスぶんなのか見分けられません。機械に決めさせると、賞与の10万円が
古い月々の回に食われて、台帳の金額がおかしくなります。だから人が選びます。

選んだ種類の回をすべて払い終えている方の入金は、充てる先がなく**余り**になります。
その場合は取り込んだあとに知らせが出ますので、入金履歴からその行を押して、
**入金種類を直してください。**

### 取り込まない振込人（除外リスト）

会社の口座どうしの振替や、手数料の戻しは、毎月のCSVに必ず出てきます。
そのたびにチェックを外していると、いつか外し忘れます。

確認の表の上にある**「除外リストを確認・編集」**から、その振込人を入れておいてください。
**次からは、CSVからでも銀行からでも、毎回自動で外します。**

- **顧客が決まっていない振込人**は、名前を押すだけで入れられます
- お客様の名前は候補に出しません（押し間違えると、その方の入金が入らなくなるため）。
  どうしても入れるときは、手で打ってください
- **覚え書き**（例：会社の振替）を添えておくと、あとで見て分かります
- 「外す」を押せば、また表に出るようになります
- **すでに取り込んだ入金は消えません。**これから読むぶんに効きます

外した行は黙って落としません。確認の画面に
**「◯行は、除外リストにある振込人なので外しました」**と、その名前が出ます。

### 手で1件入れる

現金で受け取ったときや、CSVに出てこない振り込みのときに使います。

- 「入金登録」タブ →「手動入金登録」
- **未入金タブの行の右**にある「手動入金登録」からも開けます（電話中はこちらが早いです）

| 欄 | 入れるもの |
|---|---|
| 日付 | 実際に入った日 |
| 金額 | 受け取った額 |
| 名前 | 打つと候補が出ます（かな・カナ・漢字・英字のどれでも当たります） |
| 入金方法 | 振り込み／現金／その他 |
| 入金種類 | **ボーナス払いの方にだけ出ます**（下記） |
| メモ | **手で入れた理由を必ず書いてください**（例：現金で受け取った） |

登録すると「3回目へ 30,000円」のように、どの回に充てたかが出ます。

### ボーナス払いの入金

ボーナス払いの設定がある方は、**「入金種類」**の欄が出ます。
選べるのは **月額** と **ボーナス** の2つです。

- はじめから、**いま払えていない分の種類**が入っています。たいていはそのままで結構です
- 未入金タブの<kbd>ボーナス</kbd>の行から開いたときは、ボーナスで始まります

**なぜ分けるのか。** 台帳はふつう、期日の古い順にお金を充てます。
そのため、賞与で受け取った10万円が、古い月々の回に食われてしまい、
ボーナスの回はいつまでも未入金のまま残っていました。
種類を選べば、**その種類の回にだけ**充てます。

CSVや銀行から取り込むときも、確認の表の**「入金種類」**でボーナスを選べます。
現金で受け取ったときや、CSVに出てこない振り込みのときは、こちらを使ってください。

### 入金を間違えたとき

「入金履歴」タブで、その行を押します。

- **直す** — 日付・金額・顧客・入金方法・メモを直せます。充当も自動で付け直します
- **取り消す** — 「この入金を削除」。充当も一緒に外れます

どちらも記録に残ります。顧客を付け替えたときは、**移す前と移した先の両方**に残ります。

ボーナスとして入れた入金を直しても、**ボーナスのまま**です。勝手に月額へ移りません。

## 顧客の管理

### 新しく登録する

「顧客一覧」→「＋ 新規顧客登録」

| 欄 | 補足 |
|---|---|
| 名前 | 必須 |
| よみ（カナ） | **必ず入れてください。** あいうえお順と、CSVの振込人名の照合に使います。あとから顧客一覧の「よみを入れる／よみを直す」でまとめて入れる・直すこともできます |
| 性別・生年月日・電話番号・住所 | 分かる範囲で |
| 契約日・車種 | 分かる範囲で |
| 債権譲渡会社・債権譲渡先 | 「設定」タブで会社を登録してから選べます |
| 月々の金額・支払回数 | **あとから変えられません**（下記） |
| 毎月の支払日・支払い開始月 | あとから直せます（下記） |

登録すると、支払予定が回数ぶん自動で作られます。
毎月の支払日がその月に無いとき（31日など）は、その月の末日になります。

### よみ（カナ）をまとめて入れる・直す

**よみが入っていないと、CSVの振込人名からお客様を当てられません。**
銀行の明細は `ｳｻﾐ ﾏｺﾄ` のようなカナで来るためです。よみが空のままだと、
取り込んだ入金を1件ずつ手で割り当てることになります。

**顧客一覧の右上**に入口があります。空の方がいるあいだは「よみを入れる（◯名）」、
全員そろうと**「よみを直す」**に変わります。**入口は消えません。**
読み方が違っていたら、あとからここで直せます。

押すと一覧で並び、上から順に打てます。空の方がいるあいだは空の方だけが出ます
（全員そろっているときは、はじめから全員が出ます）。
上の**「よみが空の方だけ出す」**のチェックを外せば、いつでも全員を出せます。

- **ひらがなでも半角カナでも構いません。** 保存するときに全角カナへそろえます
- **「苗字の辞書から候補を入れる」**を押すと、空いているところに苗字の読みが入ります。
  すでに入っているところは触りません
- **候補は下書きです。正解ではありません。** 読みが分かれる苗字（小田・恩地・清島など）は
  候補を出さず、「確かめてください」と理由を出します
- **下の名前まで入れておくと、同じ苗字の方がいても取り違えません**
- 打ち終えたら「◯名を保存する」。誰のよみをどう変えたかは記録に残ります

### 情報を直す

お客様のページの右上「顧客情報を編集」から直せます。

**次の2つは、ここでは変えられません。**

- 月々の金額
- 支払回数

変えると支払予定を作り直すことになり、**すでに充てた入金の行き先が消える**ためです。
どうしても直す必要があるときは、デバッグ依頼から相談してください。

#### 支払い開始月・毎月の支払日は直せます

「1回目は3月6日ではなく6月6日からだった」のような、登録のときの間違いを直せます。

- **全部の回の期日が、まとめてずれます。**押す前に、1回目がいつになるかを出します
- **入金は動きません。**どの回にいくら入っているかはそのままで、期日だけを直します
- 金額・回数・残債も変わりません
- ボーナスの回も、新しい期間に合わせて置き直します
  （すでに入金が充てられているボーナスの回は動かしません）
- 何をどう直したかは記録に残ります

### 口座振替（自動引き落とし）の状態

お客様のページの帯の右端、**「口座振替（押すと変えられます）」**を押します。

| 状態 | 意味 |
|---|---|
| 未申込 | まだ手続きしていません |
| 口座振替申込 | 申し込みました（申し込んだ日を入れます） |
| 口座振替開始 | 引き落としが始まりました（始まる日を入れます） |
| 口座振替停止 | 止めました |

### ボーナス払いの設定

「顧客情報を編集」の中にあります。

1. 12か月の札から、**ボーナス月を押して選びます**（複数選べます）
2. 選ぶと日と金額の欄が出るので、入れます
3. 保存すると、その月日に**別の回**として支払予定に足されます

- 支払総額と残債にも足されます
- 契約の期間（初回の期日〜最終回の期日）に入る月だけ作られます
- **すでに入金が充てられているボーナスの回は消えません。** 入金の行き先が消えないためです

支払いの記録では「全48回 + ボーナス4回」のように出て、
ボーナスの回は <kbd>賞与1</kbd> と紫色で出ます。

### 車を引き上げた

「顧客情報を編集」→「取引の状態」で**「車両を引き上げ」**を選び、引き上げた日を入れます。

- 未入金タブから消えます（引き上げた方に督促の電話はしません）
- 「完済/引き上げ」タブに移ります
- 顧客一覧では行の背景が薄い灰色になります

払い終えた方は、何もしなくても自動で「完済」になります。

**支払期日が過ぎた回だけ**を数えています。まだ期日の来ていない回は入りません。
**全部回収できた月は消えます。** 残っている月は、古くても出し続けます。

車を引き上げた方と、テスト用の顧客は入っていません。

終わった取引（完済・引き上げ）は、行の背景が薄い灰色です。

- 上の欄で名前から探せます
- お客様の名前を押すと、その方のページが開きます

### 完済/引き上げ

終わった取引です。<kbd>完済</kbd> と <kbd>引き上げ</kbd> の区分が付きます。

## 経営者の方へ：数字の読み方

### 回収率

ダッシュボードの％は、**支払期日が過ぎた回のうち、入金済みの回の割合**です。
まだ期日の来ていない回は分母に入りません。ですから、
**「これから来る支払い」で薄まることはありません。**

### 残債

その方の支払総額から、これまでの入金合計を引いた額です。
ボーナス払いを設定していれば、その分も入っています。

未入金タブでは、月額の行とボーナスの行の**両方に同じ残債**が出ます。
残債は「その人にいくら残っているか」であり、種類で割れる数字ではないためです。

### いま危ないのは誰か

ダッシュボードで**赤い背景の行**を見てください。複数の月に出ている方です。
1か月遅れの方より、3か月ためている方のほうが先に手を打つ必要があります。

### 数字に入らないもの

- 車を引き上げた方（督促も請求もしないため）
- テスト用の顧客（試し打ちの金額が混ざらないようにするため）

## 困ったとき

### よくある質問

**Q. 入金を間違えた顧客に入れてしまいました**
A. 入金履歴でその行を押し、顧客を選び直してください。充当は自動で付け直します。
移す前と移した先の両方に記録が残ります。

**Q. まとめて2か月分が振り込まれました**
A. そのまま1件で入れてください。古い回から順に自動で埋まります。

**Q. ボーナスの入金なのに、古い月の回に入ってしまいました**
A. 入金履歴でその行を押し、**入金種類を「ボーナス」**に直してください。
ボーナスの回に入り直します。
次からは、取り込む前の確認で、その行の**入金種類を「ボーナス」**にしてください。

**Q. 取り込んだら「選んだ種類の回に充てきれませんでした」と出ました**
A. 選んだ種類の回が、すべて払い終わっているという意味です。
ボーナスの回が残っている方なら、その入金はボーナス分です。
入金履歴からその行を押して、**入金種類を「ボーナス」**に直してください。

**Q. 毎月、会社の振替がCSVに出てきます**
A. 取り込む前の確認から**「除外リストを確認・編集」**を開き、その振込人を入れてください。
次からは毎回自動で外します。

**Q. 「未入金」に同じ名前が2行出ています**
A. 間違いではありません。ボーナス払いの方は、月額とボーナスを別の行に分けています。

**Q. 約束を入れたのに、期日が変わりません**
A. そういう作りです。期日は契約上のものなので動きません。約束は別に残ります。

**Q. 月々の金額を間違えて登録しました**
A. あとから変えられません。すでに充てた入金の行き先が消えるためです。
デバッグ依頼から相談してください。

**Q. 支払いの始まりの月を間違えて登録しました**
A. 「顧客情報を編集」の**支払い開始月**で直せます。
全部の回の期日がまとめてずれますが、**入金は動きません。**

**Q. CSVを2回取り込んでしまいました**
A. 2回目は自動で弾かれます。確認画面に <kbd>取込済み</kbd> と出て、最初から外れています。

**Q. 画面が真っ白／古い内容のままです**
A. 画面を**強く更新**してください（Windows は Ctrl + Shift + R、Mac は ⌘ + Shift + R）。

**Q. 誰がこの入金を入れたのか知りたいです**
A. いまの台帳では分かりません。記録者はすべて「管理者」になります。
残したいことは、メモに名前を書いてください。

### うまくいかないときは「デバッグ依頼」

「デバッグ依頼」タブから報告できます。

1. **タイトル** — ひとことで（例：未入金の合計が合わない）
2. **本文** — **どの画面で、何をしたら、どうなったか**を書いてください
3. **画像** — 画面を撮って添付してください。欄に貼り付け（Ctrl + V）でも入ります

投稿には返信できます。追加で分かったことは、返信で足してください。

**書き方の例**

> 未入金タブで、山田太郎さんの「未督促」を押したら、
> 確認は出たのに印が変わりませんでした。
> 画面を更新すると変わっていました。（8/9 14時ごろ、スマホ）

「動かない」だけでは調べようがありません。**画面・操作・結果**の3つを書いてください。

## やってはいけないこと

- **本物のお客様で操作を練習しない** — 「設定」タブのテスト用の顧客を使ってください
- **あとでまとめて控えようとしない** — 電話を切った直後に入れてください。忘れます
- **CSVを確かめずに取り込まない** — 取り込む前の確認画面は必ず読んでください
- **共用のパソコンでログアウトを忘れない** — 席を離れる前に押してください
- **間違いを放置しない** — 直した記録は残ります。隠すより直すほうが安全です

## 付録：この台帳の決めごと

新人の方は読まなくて構いません。運用を決める方向けです。

| 決めごと | 理由 |
|---|---|
| 支払期日は約束では動かない | 分割の約束を何件も入れると期日が跳ね回り、契約上の期日が分からなくなるため |
| 入金は「充当」で回に割り振る | まとめ払いを1件の入金として受け、複数の回へ按分するため |
| 満額に届くまでは「一部入金」 | 届いてはじめて「入金済み」。残りが見えなくなるのを防ぐため |
| 記録（event）は追記のみ | 消せる台帳は台帳ではないため。訂正は「取消」を足して表す |
| 督促は回ごとに持つ | 顧客ごとに持つと、次の月になっても「督促済み」のままになり、かけ忘れが分からなくなるため |
| 通常とボーナスは回次を別に数える | 「全48回 + ボーナス4回」と数えるため |
| ログインは全員で共通（8時間） | 担当者ごとの利用者はまだ作っていません |

技術的な詳細は `docs/データ保存設計.md` にあります。
