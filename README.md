# 入金管理台帳

自社割賦(車を自社の分割払いで売る)の入金を管理する台帳。
電話を受ける担当者が使い、経営者の質問にもここで答える。

## 画面

ヘッダーに5つのタブ。

| タブ | すること |
|---|---|
| **顧客一覧** | 氏名・債権譲渡会社・車種・毎月の支払日・金額・残り支払い回数・残債金額。右上から新規顧客登録 |
| **入金登録** | 上に CSV 取り込み、下に手動入金 |
| **入金履歴** | 当日を最新に降順で30件。直せる。顧客検索つき |
| **未入金** | 期日までに入金できていない顧客をあいうえお順で。行を押すと入金履歴へ移る |
| **設定** | 債権会社の登録 |

顧客一覧の行を押すと**顧客ページ**が開く。左7割が月カレンダー、右3割が支払いの記録。
カレンダーには固定の支払日が出ていて、日付を押すとその日に入金約束を足せる
(約束日・何時まで/終日・どの回ぶんいくら・メモ)。顧客についてのメモも持てる。

## 決めごと

- **期日は動かない。** 入金約束をいくつ足しても、契約で決まった支払日は変わらない
- **1回ぶんに約束を何件でも足せる。** 「3日後に半分、5日後に残り」が日常のため
- **1件の入金を複数の回に按分できる。** まとめ払いも分割入金も同じ仕組みで扱う
- **満額に届くまでは「一部入金」。** 届いてはじめて「入金済み」
- **手動入金は理由(メモ)が必須で、履歴では行の背景を変える**
- **記録(`event`)は消せない。** 訂正は「取消」を足す。データベース側でも禁止している
- **顧客検索は かな / 全角カナ / 半角カナ / 半角英字 / 全角英字 のどれでも当たる**
- **スマホ・iPad のホーム画面に置ける。** 電波が無いと開くところまで
  （台帳の中身はサーバーにある）

## 構成

```
index.html, src/       画面(React + Vite)
public/                アイコン・manifest・受け皿(sw.js)
tools/icons.mjs        アイコンを描いて撮る（node tools/icons.mjs）
api/*.js               Vercel の関数(ESM)
api/_*.js              共通部品(スキーマ・DB・正規化・CSV解析)
docs/データ保存設計.md   テーブル・API・名寄せ・載せ替えの設計
DEPLOY.md              Vercel での公開手順と初回の作業
引き継ぎ資料/           もとの仕様・ADR・移行手順・未決事項
```

## 使いはじめ

`DEPLOY.md` を読むこと。環境変数を入れ、`POST /api/setup` でテーブルと
既存データを入れてから、設定タブで債権会社を登録する。

**テーブルの用意と載せ替えは画面に置いていない。** 移行のときに一度使うだけで、
日々使う人の設定タブに置いておくと誤って押されるため。
